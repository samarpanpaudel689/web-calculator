# Modern Web Calculator

A sleek, responsive, modern calculator built using HTML, CSS, and vanilla JavaScript.

## Features

- **Modern Dark UI**: Clean interface built with modern typography and fluid styling.
- **Full Arithmetic Operations**: Addition, subtraction, multiplication, division.
- **Additional Functions**: Percentage calculation, sign toggling (±), backspace deletion, and clear (AC).
- **Scientific Mode**: Toggle between Basic and Scientific layouts for advanced calculations:
  - Trigonometry (sin / cos / tan) with a **DEG / RAD** angle toggle
  - log, ln, √, ∛ (cube root), x², x³, xʸ (powers), n! (factorial)
  - reciprocal (1/x), absolute value (|x|), modulo (mod)
  - Constants π and e
  - Error-safe handling for invalid inputs (e.g. sqrt of a negative, log(0), division by zero)
- **Keyboard Support**: Full support for physical keyboard input (`0-9`, `.`, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`).
- **Formatted Numbers**: Automated comma separation for large numbers.
- **Responsive Design**: Mobile-friendly layout.

## Getting Started

Simply open `index.html` in any modern web browser to use the calculator.

Alternatively, view it using GitHub Pages if enabled.
